# Viewing the Berkshire County Example

This folder includes a sample calculator generated by the
`home-affordability-calculator` skill, using Berkshire County,
Massachusetts as the example location. This file shows you exactly what the
skill produces, without needing to install anything or run the skill
yourself first.

## How to view it

The file is a single self-contained HTML page. No server, no installation,
and no account are required.

**Option 1: Double-click it**

Find `berkshire_county_affordability_calculator.html` on your computer and
double-click it. It will open in your default web browser (Chrome, Safari,
Firefox, or Edge all work fine).

**Option 2: Open it from your browser**

1. Open any web browser.
2. Press `Ctrl+O` (Windows/Linux) or `Cmd+O` (Mac) to open the file picker.
3. Navigate to `berkshire_county_affordability_calculator.html` and select
   it.

**Option 3: Drag and drop**

Drag the file directly from your file explorer or Finder window into an
open browser window.

## What you'll see

Once it's open, you can move the sliders for home price, down payment,
property tax, and home size, and the numbers update instantly:

- Total monthly housing cost
- Loan amount
- Back-end debt-to-income (DTI) ratio
- A color-coded verdict (green, amber, or red) showing how comfortable that
  scenario is

Everything runs in your browser using JavaScript. No data is sent
anywhere, saved anywhere, or shared with anyone. Closing the tab clears
whatever you changed; reopening the file resets it to the original example
numbers.

## About this example

The numbers in this file were researched for Berkshire County, MA at the
time it was generated:

- Property tax: 1.62% effective rate (Berkshire County median)
- Mortgage rate: 6.5% (a recent national 30-year average)
- Home sizes compared: 2,000 sqft and 3,200 sqft
- Down payment: $150,000
- Gross annual income: $130,000
- Monthly debt: $450

These are a snapshot, not a live feed. Property tax rates, utility costs,
and mortgage rates all change over time, so treat this file as a
demonstration of what the tool produces, not as current data for Berkshire
County. If you want up-to-date numbers for this or any other location, run
the skill again rather than relying on this saved example.
