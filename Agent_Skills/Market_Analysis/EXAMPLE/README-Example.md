# Market-Analysis Skill — Example Output

This folder contains a **fictional, illustrative example** of what the `market-analysis` skill produces, generated to show the format and structure — not real research.

## Files

- `market-analysis-example.md` — a mock competitive intelligence package for a made-up market ("shift-management software for hourly workforces"), with an invented product (ShiftPilot) and invented competitors (Rotalink, CrewCast, ShiftHarbor, PunchLine).

## What's fictional here

Everything. Market name, company names, pricing, statistics, quotes, review complaints — all invented for demonstration. Any resemblance to real companies is coincidental. No web research was performed to produce this file.

## What a real run looks like (and how this differs from it)

| | This example | A real run |
|---|---|---|
| Research | None — content written directly | 3 sequential waves, 2 parallel threads each, all backed by live web search |
| Confidence tags | Everything marked `[Assumption]` or "illustrative" | Every claim tagged `[Data]`, `[Estimate]`, or `[Assumption]` based on actual source strength |
| Data gaps | One or two shown as format samples | Every genuine gap in the real research gets flagged with impact + suggested follow-up |
| Delivery | All 4 deliverables shown at once | Presented one at a time — report → matrix → pricing map → battle cards — pausing after each for feedback |
| Time/cost | Instant | Takes real time and search calls; worth it because the output is grounded in current data, not stale training knowledge |

## The four deliverables

1. **Executive intelligence report** — market landscape, competitor tiers, opportunities, risks, moat assessment, data gaps.
2. **Competitive feature matrix** — Strong / Adequate / Weak / Missing / Unknown rating per feature per competitor, plus a "your product" column.
3. **Pricing landscape** — tier-by-tier pricing, value-metric analysis, pricing psychology, positioning map, whitespace.
4. **Battle cards** — one per competitor: honest strengths, evidence-backed weaknesses, when you win, when you lose, key vulnerability.

## Why the honesty protocol matters

The skill's core rule: every claim is confidence-tagged, and genuine data gaps are labeled `DATA GAP` rather than filled with a plausible-sounding guess. A battle card that hides a competitor's real strengths, or a report that presents an estimate as verified fact, is worse than useless for actual decision-making — it's actively misleading.

## Running it for real

To get an actual analysis instead of this mock-up, invoke `/market-analysis` and provide:
1. The market or product idea
2. Your target customer
3. Known competitors (or "starting cold")
4. Your differentiator, if you have one
5. The single most important question you want answered

The skill will run the real research waves and cite live sources instead of inventing them.
